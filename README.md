# 🚗 Smart Parking System

An Arduino-based smart parking system developed and simulated using Tinkercad.

## 📌 About the Project

The project monitors parking slot availability using ultrasonic sensors and provides visual information about occupied and available slots.

The system was developed as an electronics/embedded systems project to understand sensor-based parking management and Arduino programming.

## ✨ Features

- 🚗 Parking slot detection
- 📡 Ultrasonic sensor-based distance measurement
- 💡 LED indication for parking slot status
- 🖥️ LCD display for parking information
- 🔢 Multiple parking slots
- 🔌 Arduino-based control

## 🛠️ Components / Technologies

- Arduino
- Ultrasonic sensors
- LEDs
- LCD display
- Potentiometer
- Arduino programming
- Tinkercad Circuits
